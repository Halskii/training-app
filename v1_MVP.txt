v1

Must have:
Easily accessible and editable 12 week training programs in 4 week blocks generated by the AI model.
A user should be able to track long-term and training phase goals. If a user inputs goals there must be a 'Suggest Pathways' feature where the AI model must generate subtasks for each goals to help the user actually reach them, likewise when it's a training phase goal such as "I have a competition in X weeks" they should be prompted for the events in the competition, and the programming should adjust to the events in the competition etc.
The AI model must consider 3 blocks at a time, an accumulation phase, intensification phase, and realization phase, this consideration is for the optimal exercises for their goals.
A user must be able to give the AI feedback about injuries or concerns and have it adjust the programming appropriately.
A user must be able to add workout notes.

Should Have:
The template for a subscription feature, AI model requests aren't free, price TBD but keep it free at first for testing purposes.
A user should be able to track supplements easily, ideally even track PEDs. Note: The AI model will not give PED advice, this is simply a tracking tool.
The UI should be clean and aesthetically pleasing. Offer different theme colors the user can select.

Won't Have:
Paid live coaching
